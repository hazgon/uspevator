# Успеватор

Успеватор помогает выполнить цепочку задач к обещанному времени. Для каждой задачи задай оптимистичную оценку и оценку с запасом. Разница между ними образует общий резерв плана. По мере работы видно, сколько резерва осталось и как меняется прогноз финиша.

## Как начать

1. Добавь задачи в нужном порядке и оцени их время.
2. Нажми «Начать». Таймер покажет, сколько осталось по обеим оценкам. После «Готово» начнётся следующая задача.
3. Сверяй прогноз с обещанным финишем. Если порядок изменился, «Пропустить» отправит текущую задачу в конец очереди и сохранит отработанное время.

Повторяющиеся списки можно сохранять как шаблоны. Планы и шаблоны хранятся на устройстве, их можно перенести с помощью резервной копии.
